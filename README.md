# LipatoS — Уникальные предметы Айндора

Один модуль для Foundry VTT v14 и D&D 5e 6.x. Для работы ремня требуется включённый **libWrapper**.

- **Багряная мантия:** запоминает заклинания 1–3 уровня, повторяет за заряд без траты ячейки, восстанавливает заряд на продолжительном отдыхе. Поддерживает флаги прежних модулей `aindor-unique-items` и `bagryanaya-mantiya-echo`.
- **Прочный кожаный ремень:** надетый предмет типа `equipment` с точным названием «Прочный кожаный ремень» снижает текущую загруженность персонажа на 15 фунтов. Максимальная грузоподъёмность не изменяется.

## Установка

Foundry VTT → Модули → Установить модуль → URL манифеста:

`https://raw.githubusercontent.com/lipatosss/lipatos-aindor-unique-items/main/module.json`

Отключите прежние `aindor-unique-items` и `aindor-belt-weight`, чтобы не накладывать одну механику дважды. Уже существующие предметы удалять не нужно.

## Релизы

При изменении кода/манифеста workflow в GitHub Actions формирует ZIP, публикует его в GitHub Releases и обновляет архив указанной в манифесте версии.

## Вересковая медовуха (1.0.4)

После успешного использования расходуемого предмета с идентификатором `vereskovaya-medovuha` модуль применяет эффект «Вересковое тепло», бросает 1к4+1 и добавляет **одну пустую бутылку** (`pustaya-butylka`) в инвентарь использовавшего персонажа. При наличии бутылок их количество увеличивается на 1; дубликаты строк не создаются.

Шаблон бутылки ищется сначала в предметах мира, затем в инвентаре персонажей и доступных сборниках предметов. При наличии шаблона копируются исходная иконка, описание, цена (2 см), вес (0,5 фунта) и прочие настройки; шаблон не расходуется. Если шаблон отсутствует, создаётся предмет-добыча «Пустая бутылка» с запасной иконкой и выводится предупреждение. Действие на персонаже запускает один модуль: при включённых двух приоритет имеет «Баффы и дебаффы».

## Исправление 1.0.5: использование медовухи

- Убран ненадёжный WeakMap между `dnd5e.preUseActivity` и `dnd5e.postUseActivity`: D&D5e 6.x создаёт разные экземпляры Activity в начале и в конце использования.
- Обработка ведётся по успешному `dnd5e.postUseActivity` и его собственному объекту результата. Повторная доставка одного результата не создаёт второй бросок или бутылку.
- Списание заряда выполняется системой dnd5e; модуль больше не списывает его повторно. Если настройка `autoDestroy` включена, полностью израсходованная одиночная медовуха исчезает, а для стопки из нескольких бутылок уменьшается количество и сбрасывается счётчик зарядов.
- После применения «Верескового тепла» создаётся один предмет `pustaya-butylka` либо увеличивается его количество. При наличии исходного предмета мира сохраняются изображение и характеристики.

## Исправление 1.0.6: трата заряда не запускала баф

Для D&D5e v6.0.6 после реального списания заряда добавлен надёжный обработчик `updateItem` с проверкой `system.uses.spent`. Он самостоятельно запускает бросок `1d4+1`, эффект «Вересковое тепло» и возвращает `pustaya-butylka`, даже если `dnd5e.postUseActivity` не запустился. При штатной активности обработчик `postUseActivity` остаётся резервным, но один расход не может выдать две бутылки.

При `autoDestroy` полностью израсходованная медовуха удаляется. Оригинальная иконка бутылки берётся из предметов мира/сборника, если шаблон найден. Срабатывание действий доступно пользователю, который инициировал расход, и не повторяется на клиентах остальных игроков. Для диагностики откройте F12 и найдите сообщение «Вересковая медовуха: событие updateItem».

## Описание «Вересковое тепло» (1.0.7)

Описание эффекта сокращено: динамически выводится **результат последнего броска** временных хитов и преимущество против испуга на 1 час. Убраны мировое время и лишние строки. Сама механика медовухи не изменена.
